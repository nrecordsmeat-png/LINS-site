# LINS-site

Открытый сайт: готовые разборы text-check и механика текста прямо в браузере (текст никуда не отправляется).

Адрес после включения GitHub Pages: https://nrecordsmeat-png.github.io/LINS-site/

## Что можно сюда класть

Только то, что автор отдельно разрешил показать. Прогоны собственных текстов из закрытого репозитория
сюда не попадают. Перед публикацией разбора проверить: в отчёте и карте встроен весь текст и пересказы читателей.

## Как устроено

- `index.html` — главная: галерея разборов, механика, описание метода.
- `reports/` — файлы разборов и `index.json` со списком.
- `viewer/roots_view.html` — просмотрщик карты корней. Исходник лежит в закрытом репозитории
  (`text-check/viewer/`), сюда копируется байт в байт.
